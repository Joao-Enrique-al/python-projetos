# 🐍 Python projetos

Uma coleção de pequenos projetos que desenvolvi em Python durante meus estudos e prática de programação.

A ideia deste repositório é registrar minha evolução e experimentar diferentes conceitos da linguagem, desde programas simples no terminal até algumas aplicações com Tkinter.

## 📚 Sobre

Projetos feitos principalmente para aprendizado e prática.

Durante o desenvolvimento, explorei conceitos como:

* Variáveis e estruturas de dados
* Condicionais e loops
* Funções
* Listas e dicionários
* Manipulação de arquivos
* APIs
* Bibliotecas do Python
* Programação orientada a pequenos projetos
* Interfaces gráficas com Tkinter

## 🚀 Projetos

A coleção possui projetos de diferentes níveis, incluindo:

* 🎮 Jogos simples
* 🧮 Calculadoras
* 📝 Gerenciadores de tarefas
* 💰 Controle financeiro
* 🔐 Gerador de senhas
* ⏱️ Timers
* 🤖 Chatbot simples
* 🎨 Aplicativo de desenho
* 🖥️ Aplicações com Tkinter
* 🌐 Projetos utilizando APIs

Cada projeto foi desenvolvido como uma forma de praticar e entender melhor algum conceito.

## 🎯 Objetivo

Este repositório não tem como objetivo apresentar projetos profissionais. É principalmente um espaço para acompanhar meu aprendizado em Python e guardar alguns dos exercícios e projetos que desenvolvi ao longo do caminho.

> Aprender programando, errando, corrigindo e tentando novamente. 🐍
